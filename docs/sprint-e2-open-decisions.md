## 4. 本机已完成、可作批准参考的演练数字

- E2.1：真实镜像启动约 15.6 秒；空库 V1 45 / V2 8 迁移；健康 200；登录后 `/v2` 200；cron 首轮成功（库存 308ms、订单过期 10ms）。
- E2.3：备份集（V1+V2）约 3–5 秒；V2 恢复到隔离库约 3.4–6.6 秒；迁移历史 8、关键表行数与备份基线一致；坏归档/目标冲突/失败保留均按预期停止。
- E2.2：同版本重试成功；镜像不存在在替换前退出且现有栈保持健康；坏镜像健康失败 180 秒停止且不启 cron、旧镜像保留；受控迁移失败 P3018 退出非零并保留未完成迁移记录。

以上数字来自本机合成数据与单机 Docker，生产批准前需在远程 staging 用真实数据量与真实镜像 digest 复跑。
