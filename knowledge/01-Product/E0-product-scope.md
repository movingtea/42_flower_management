# 产品范围与业务术语

V2 第一阶段围绕门店 WMS 的实际业务闭环，覆盖物料、商品与配方、采购验收、库存、后台订单、制作及交付。CRM、CMS、小程序和完整经营报表按后续范围处理，具体 V1/V2 入口见 [[E0-v1-v2-ownership]]。

| 术语 | 项目含义 |
|---|---|
| 经营主体、门店 | 主数据归经营主体，订单与实际库存作业按门店划分。最终授权范围见待确认清单。 |
| 物料、批次、库位 | 物料描述品种、等级或规格。批次承载到货、效期和成本信息。库位表示物理或作业位置。 |
| 商品、SKU、样品 | 商品聚合可售规格。SKU 有独立价格和配方。样品可作为 SKU 草稿起点。 |
| 配方版本 | SKU 制作所需物料与数量的版本。订单与版本的绑定规则见待确认清单。 |
| 缺料需求、采购分配 | 前者记录订单缺口，后者记录采购明细中分给需求的数量。 |
| 临时锁定、正式预留 | 前者用于待支付能力锁定，后者关联正式需求与批次。 |
| 交付、结账成本快照 | 交付表示自提或配送完成。成本快照记录结账时点的成本依据。 |
