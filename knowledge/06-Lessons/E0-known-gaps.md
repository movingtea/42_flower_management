# 已知限制、试用反馈与技术债

- Sprint 4 收口已关闭原打样三项限制：暂停/恢复（`SamplePlanState.PAUSED`，暂停释放未领用预留、按员工确认处置制作区回库/留用/报损、恢复重新检查现货并补领当前步骤缺口）、未开始直接完成（同事务补齐预留、领用与制作区流转）、顾客订单优先后的风险计划原地重算（释放旧预留、关闭未开始执行、重新计算并再次批准）。实现与验收见 [Sprint 4 证据](../../docs/stage-artifacts/sprints/sprint-4-evidence.md)。
- 2026-11-20 暂停制作区实物处置已补齐（WMS-BR-SMP-007）：暂停与取消均要求逐批确认回库/留用/报损，回库重新验收并记录最晚可用时间，报损写 `LossRecord`，留用保留在制作区；暂停时同步核减已处置预留，恢复时补领当前步骤被回库或报损的物料。
- 仍待处理：完成/取消后留在制作区的可复用物料不会自动进入普通库存或下一个计划；样品成本未写 `CostEntry`；样品图片上传未开放。以上均需后续确认，不阻塞当前打样流程。
- 启动文档记录 V2 确认后的 SKU 行增删需取消并重建，制作开始后涉及物料的变更需人工协调。确认最新边界后更新规则。
- 试用反馈保留采购关联入口、混合验收、拒收上限和替换花材库存提示的历史记录。逐项复测后关闭，旧状态以原记录为准。
- V2 Prisma 已使用正式 schema 和独立的 `V2_DATABASE_URL`。发布前需在目标环境准备 V2 数据库和连接，操作步骤见 [V2 运行与初始化](../../docs/flower-studio-2.0-local-run.md)。
- 本地启动文档记录过 Next 生成缓存导致的页面 404，dev 与 build 共享生成文件时应分开运行。
- 2026-11-19 物料母表已按 V1 FlowerWiki 补齐：迁移 `0014_material_library_parity` 增加拼音简拼、别名、花材角色、多颜色标签、形态、默认可用率/损耗率、损耗模式、成本更新时间；AI 补全扩展为颜色/形态/供货季/角色/别名建议；新增无引用硬删除与行内改标准成本。实现约定见 [[E0-v2-engineering-conventions]]。
- 2026-11-19 起物料/供应商/包装方案等业务编号由系统生成，界面不再手填；列表拆分“编号/名称”。测试数据仍可通过服务层显式传编号。约定见 [[E0-v2-engineering-conventions]]。
- 仍待处理（打样相关，不阻塞）：完成/取消后留在制作区的可复用物料不会自动进入普通库存或下一个计划；样品成本未写 `CostEntry`；样品图片上传未开放。
- 仍待处理（物料与选择器）：V2 表单内的物料/配方/分类仍是原生 `<select>`，没有统一的可搜索选择器（差距矩阵 F06，属 Sprint 5 CMS 迁移范围）；V1 `FlowerWiki` 历史数据未回填到 V2，旧库记录仍只存在于 V1。
- 2026-11-19 浏览器 E2E 已在当前环境真实跑通（此前沙箱限制 `spawn EPERM` 已解除）：全量 23 通过 / 2 失败 / 1 跳过，失败仅 `smoke.spec.ts` 的标题层级断言（Sprint 2 把“经营概览”从 h1 改为 `V2ModulePage` 的 h2，测试未同步），已修正断言；main-chain 6/6 覆盖抽屉新增/编辑、自动编号与完整订单链路。
- 2026-11-19 V2 物料按 V1 双入口模式拆分：`/v2/materials` 改为花材母表（FLOWER/FOLIAGE），新增 `/v2/consumables` 耗材母表（PACKAGING/CONSUMABLE/OTHER），共用 `Material` 模型；`/wms/master-parts` 切割重定向到耗材母表。拆分只发生在前端入口，历史 `/v2/materials` 链接仍有效。
- 2026-11-19 花材三级分类以自由文本字段维护，顺序为`flowerVariety`（种类）、`color`（颜色）、`flowerProductName`（商品名），迁移 `0015_material_flower_classification`。花材名称允许留空，服务端按“种类 · 颜色 · 商品名”自动生成，手填仍可覆盖；耗材名称仍必填。暂无分类字典、无颜色枚举，存量花材未回填；是否需要分类树或词表待业务确认。
- 2026-11-19 打样计划的三级分类复用建议只参与推荐排序与展示，并写入计划快照；实际复用仍以同一物料拆解后重新验收的可用量为准。分类相同但物料不同的组合会被推荐，但不会产生复用量或成本变化（WMS-BR-SMP-001/002/003 未变）。
- 2026-11-19 V2 首次登录改密的最小长度由 16 降为 8（`V2_BOOTSTRAP_PASSWORD_MIN_LENGTH`），其余强度规则不变（至少 8 个不同字符、不含用户名、≤72 字节）；员工创建/重置仍为最少 8 位。安全基线文档和已批准规则尚未同步，需评审确认。
- 2026-11-21 V2 第二批（打样与采购渠道）已实现：打样计划支持多个主样品并为每个主样品推荐搭配；三级匹配增加“同种类”级别；计划项可填写拍摄/留样截止并按约束自动排程；打样样品可确认换料并保留确认记录；供应商渠道损耗率会快照到采购行、验收批次，并用于打样/订单成本。证据见 [batch-2 evidence](../../docs/stage-artifacts/sprints/batch-2-evidence.md)。仍待确认：自动排程只使用固定 60 分钟/步的预测，不代表真实排产工时；渠道损耗仅调整可用成本，不改变实收入库数量；换料只覆盖样品配方，订单换料仍走既有顾客确认流程；多个留样样品同时存在时仅末步保留并给出冲突提示。
- 花材/耗材拆分后，花材抽屉不再显示品牌/型号、耗材抽屉不再显示花材专属知识字段；旧统一页时期若给对应类别填过这些字段，编辑保存会清空。V1 FlowerWiki/MasterPart 无这些组合，当前无生产数据，风险低；如需保历史值，应在保存时对未渲染字段保留原值。
