# 已确认规则 · 物料、商品、订单、配送与门店权限

## WMS-BR-MAT-001 · 物料身份与计量（RV-001）

规格影响配方选料、验收或库存互换时，建立独立物料。花材默认按品种、颜色和等级区分。长度通常参与等级判定。同等级不同长度无法互换时，拆成不同规格。供应商、进价、到货时间和效期归采购或批次。

| 物料 | 库存单位 |
|---|---|
| 花材 | 按枝。可按扎、把或箱采购，按实际枝数验收入库，记录当次换算。 |
| 花泥 | 按块。不同尺寸独立建档。 |
| 单件包材 | 按件，例如礼盒、包装袋、单张包装纸。 |
| 卷材和胶带 | 按卷入库、领用和盘点。配方可估算每单耗材成本。 |

## WMS-BR-CAT-001 · 默认 SKU 与配方版本（RV-002）

- 已发布配方锁定。纯文字错别字可追加勘误，记录操作人、时间和原因。变更花材、等级、数量、包材、制作步骤、标准损耗或客户承诺时发布新版本。
- 新版本生效后，新订单默认引用新版本，已确认订单保留原版本。未确认草稿在确认前重新校验，影响价格或交付承诺时提示员工或顾客重新确认。停用旧版本后历史订单仍可查看原配方。
- 默认 SKU 必须属于同一商品且可售。停用默认 SKU 前先选替代项。停用最后一个可售 SKU 前先下架商品。

## WMS-BR-ORD-002 · 确认后的订单变更（RV-005）

| 订单时点 | 首版处理 |
|---|---|
| 草稿 | 可修改数量、增删 SKU 行、更换规格、修改交付信息。 |
| 已确认、未开始制作 | 可修改交付时间及已有 SKU 数量。保留订单版本，重新校验供应、效期和预留。校验失败时保留原方案。改价差额以补款或退款处理。增删 SKU 行走取消并重建流程。 |
| 已开始制作 | 联系方式等不影响制作的字段可按权限修改。商品、规格或用量变化进入人工协调，记录返工、补做或售后。 |
| 已交付 | 通过售后或更正记录处理，保留原交付和结账记录。 |

换料数量和顾客确认按 [[E0-confirmed-inventory-decisions]] 中的 WMS-BR-ORD-001 执行。

## WMS-BR-FUL-001 · 配送失败与重排（RV-006）

- 配送或履约人员登记失败原因。本店履约负责人或经理可重排。重排前记录顾客确认、新交付时间和成品是否仍可交付。
- 顾客不在、临时改约或地址可纠正，且成品状态和新时效均可接受时，可重新配送。
- 成品损坏或失效、错过约定用途、顾客拒收或明确取消时转售后，由售后决定补做、重送或退款。
- 原配送尝试保留为失败。重排生成新的待配送尝试，实际出发后进入配送中。成品与材料按实际情况登记损耗或处置。

## WMS-BR-AUTH-001 · 角色和门店权限（RV-007）

员工可兼任角色。服务端按操作能力和目标门店共同校验权限。

| 角色 | 首版授权范围 |
|---|---|
| 经营主体管理员 | 管理共享主数据、门店、员工和授权，可查看本经营主体下各门店。 |
| 门店经理 | 管理本店业务、处理例外并复核。改价、退款等按独立授权执行。 |
| 采购与仓库人员 | 采购人员处理采购单和验收。仓库人员处理入库、移库、盘点和损耗。高风险差异按 WMS-BR-INV-006 复核。 |
| 花艺师 | 查看本店制作任务和必要配方、交付时间，记录实际用料、退料和制作损耗。 |
| 履约人员 | 处理本店自提、配送和失败登记，重排或退款按单独授权。 |
| 只读人员 | 查看授权范围内的数据，服务端拒绝写入。 |

同一经营主体的物料、商品、配方和供应商可按权限共享。库存、订单和顾客履约数据默认限本店。跨店查看需相应授权，跨店调货走调拨流程。账号停用后从下一次服务端请求起撤销全部业务访问。移除门店成员资格时只撤销该店访问。保留历史操作人，未完成任务由本店经理重新分派。
