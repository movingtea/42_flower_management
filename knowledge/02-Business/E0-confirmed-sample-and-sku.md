# 已确认规则 · 打样、样品与 SKU

| ID | 已确认规则 |
|---|---|
| WMS-BR-SMP-001 | 打样拆解花材可在计划内模拟复用。进入普通可售库存前，重新验收等级和最晚可用时间。 |
| WMS-BR-SMP-002 | 批准打样时重新检查现货，只预留首次制作所需花材。后续拆解预期量属于预测。 |
| WMS-BR-SMP-003 | 每次拆解后按实际可复用量重算余下步骤。低于预测时提示补购、调整顺序或缩减计划。 |
| WMS-BR-SMP-004 | 已确认顾客订单的批次预留优先于尚未开始的打样。发生竞争时标记打样风险，由员工决定改期或补购。 |
| WMS-BR-SMP-005 | 开始打样时记录操作人并自动流转首次预留花材。直接完成时补齐可验证的流转。库存不足或批次不明时进入异常处理。 |
| WMS-BR-SMP-006 | 拆解时由员工确认实际物料、等级和数量，确认后才可用于下一步打样。 |
| WMS-BR-SMP-007 | 打样暂停或取消时释放未领用预留。进入制作区的花材由员工确认回库、留用或报损数量。 |
| WMS-BR-SMP-008 | 完成样品保留在样品库。员工发起转可售 SKU，补齐价格、规格和配方并通过上架检查。商品可包含来自不同样品的 SKU，同一样品可派生多个 SKU。每个 SKU 独立维护价格与配方，样品及其他 SKU 后续变更不会传播。 |
| WMS-BR-SMP-009 | 拆解记录来源样品和拆解时间，并检查最晚可用时间。打样批准与顾客订单预留并发时用事务防止重复分配，已有顾客订单预留优先，打样冲突时重算。 |

批准依据为来源中标记「已确认」的条目。打样完整流程的交付阶段见 [[E0-product-scope]]。
