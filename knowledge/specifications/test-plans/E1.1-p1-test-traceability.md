# E1.1 P1 测试策略与追踪矩阵

## 范围和判定方法

基线为 `99daac6`。本次优先追踪 P1 门店 WMS 的高风险规则和实际试用路径，包括采购、库存、订单、制作、配送、成本及权限。V1 旧测试保留在 E1.2 的接入盘点中。第一阶段试用清单和历史差距矩阵的范围与状态存在时间差，不能直接用于判定 P1 是否完成。

场景 ID 是本矩阵的编号。当前功能规格入口仍为来源索引，矩阵使用已批准规则 ID 或 ADR 条款作为来源锚点。独立 Feature Spec AC 编号待建立后回填。证据路径相对 `flower-wms-system`，服务测试位于 `src/v2/services`，冒烟位于 `scripts/v2`。

- **已验证**表示现有断言及运行证据支持该行列出的场景。
- **部分**表示列出的断言通过，规则还有未验证或未实现的分支。
- **偏差**表示实际断言支持的行为与已批准规则存在差异。
- **人工**表示已有浏览器实操证据，自动化浏览器检查待 E1.5。
- 全部场景的 CI 证据暂为待接入。E0 实操证据见 [[ADR-003-inventory-invariants#浏览器实操验收]]。
